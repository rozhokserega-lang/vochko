## Повторный запуск

Нужны Node.js, пакет `playwright` и установленный Microsoft Edge. Скрипты запускаются из корня репозитория:

```sh
npm install --no-save playwright
node tests/playtest/consumable-audit.cjs
node tests/playtest/playtest-runs.cjs
```

По умолчанию проверяется локальный `index.html`. Переменная окружения `GAME_URL` позволяет выбрать другой адрес; `PLAYWRIGHT_MODULE` — путь к уже установленному модулю Playwright. JSON рядом со скриптами перезаписывается результатом нового запуска. Значения при повторе могут отличаться: состояние разблокировок и случайность инициализации не полностью изолированы.
