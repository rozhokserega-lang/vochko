# Проверки игры

Нужны Node.js 20+ и Playwright. Установка из корня проекта:

```sh
npm ci
npx playwright install chromium
npm test
npm run test:balance
npm run test:balance:lab
```

На macOS с установленным Google Chrome скрипты используют его автоматически. На остальных системах по умолчанию используется Chromium, установленный Playwright. Можно задать `BROWSER_CHANNEL=chrome`, `BROWSER_CHANNEL=msedge` или `BROWSER_PATH` — путь к исполняемому файлу браузера.

Дополнительные параметры:

- `PLAYWRIGHT_MODULE` — путь к уже установленному Playwright.
- `GAME_URL` — адрес проверяемой копии игры; по умолчанию локальный `index.html`.
- `TEST_OUTPUT_DIR` — папка JSON-отчётов; по умолчанию `test-results/`.
- `SEEDS` — число забегов для каждой из семи стратегий (по умолчанию 40).
- `LAB_SEEDS` — число сидов на плечо в лаборатории баланса (по умолчанию 40; для отчёта использовано 300).
- `LAB_ONLY` — группы или имена плеч лаборатории через запятую: `policies`, `decks`, `stakes`, `upgrades`, `wild`, `jokers` или `joker:counter`.
- `LAB_RAW=1` — сохранить в `balance-lab.json` сырые забеги (около 137 МБ на 300 сидах).

`npm run test:balance:lab` запускает 77 контролируемых плеч: стратегии магазина, колоды, сложности, закалки/моды, масштабирование «Дикой» и по одному джокеру на старте. Первый сид каждого плеча повторяется с полным сравнением. Отчёт с таблицами и доверительными интервалами: `node tests/playtest/balance-report.cjs`. Сводка большого прогона на 300 сидах лежит в `tests/playtest/balance-lab-300.json`.

`npm test` запускает аудит расходников и проверки предпросмотра, переноса, удаления, скрытых карт, случайности, Алхимика, ограничений боссов, «Синхронизации», разбора урона, поражения, покупок, восстановления сохранения и размеров экрана 320/390/768/1280 px. Любое несовпадение даёт ненулевой код завершения. `findings` в актуальном аудите — неуспешные проверки, открытые вопросы дизайна описываются отдельно в документации.

`npm run test:balance` проверяет семь стратегий по 40 забегов. Ошибка партии, незавершённая партия или несовпадение повторного прогона дают ненулевой код завершения. Обычное поражение — корректный исход, а не ошибка теста.

Каждый забег получает отдельное начальное состояние прогресса и генератора случайных чисел; первое начальное число каждой стратегии дополнительно запускается дважды с полным сравнением результата. В тестовом профиле все предметы и колоды открыты, но постоянных покупок нет. Отрисовка и задержки в серии отключены. Настоящие функции боя, покупок, предметов и переходов сохранены. Бот видит порядок добора только при активном игровом просмотре.

Бот использует прогноз для расходников, переноса, удаления и подмены; просмотр помогает решить, остановиться или добрать, а сжигание — убрать известную опасную карту. Джокеры оцениваются на фиксированном наборе примерных рук с учётом имеющейся сборки, слабые могут заменяться. Реликвии выбираются по простым приоритетам здоровья, защиты, экономики и слотов. Это эвристика, не оптимальный игрок. Бот идёт прямым маршрутом, не исследует события/кузницу и не планирует несколько ходов вперёд.

[Актуальные результаты и ограничения](../../BALANCE.md). Большой лабораторный прогон: [BALANCE-LAB.md](../../BALANCE-LAB.md).

Файлы `consumable-audit.json` и `playtest-runs.json` в этой папке — исторические результаты первоначальных 120 забегов. Новые запуски их не перезаписывают. Старый отчёт: [PLAYTEST.md](../../PLAYTEST.md).
