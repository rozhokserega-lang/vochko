# Шкаф, джокеры и броня PvP

Версия 5 ноября 2026. Пока это тренировочная дуэль с ИИ; сетевой подбор ещё не реализован.

## Подготовка

Шкаф из комнаты и подготовка PvP используют единый интерфейс полок по макету пользователя: класс, джокеры, таро. На полках горизонтальная прокрутка. Вес и покупка силы в PvP не используются. Всем доступны одинаковые предметы.

Для старта требуется ровно один из трёх классов, два разных джокера из шести и три разных таро. Есть начальный заполненный набор, который можно заменить. Проверка выполняется сервером; после старта сборка копируется в бой и не меняется до его завершения. Кампания сохраняет прежние боевые эффекты и лимит до четырёх таро.

## Классы

| Класс | Эффект дуэли |
|---|---|
| Картёжник | +1 урон каждому точному столу |
| Лекарь | +1 HP за красное сочетание, максимум +3 HP за раунд |
| Хранитель | 2 брони на обмен ударами, если есть карты и нет переборов |

У всех 100 HP. Красное/чёрное сочетание требует не меньше трёх обычных карт соответствующего цвета, как в базовых правилах.

## Джокеры

| Джокер | Эффект |
|---|---|
| Красная рука | Дополнительно +1 HP за красное сочетание; максимум +3 за раунд |
| Чёрная краска | +1 урон чёрному сочетанию |
| Тройной удар | +1 урон безопасному столу с тремя обычными картами; таро не считается обычной картой |
| Тандем | Две одинаковые непустые безопасные суммы: +2 общего урона один раз за раунд |
| Лесенка | Три непустые безопасные последовательные суммы: +3 общего урона |
| Сканер | По нажатию на карту джокера показывает следующую карту своей колоды; два использования за матч |

Обе пары лежат на сукне и подписаны. Класс и джокеры соперника публичны; его выбранные таро заранее не передаются клиенту. Для Сканера видны оставшиеся заряды. Нельзя повторно списать заряд за уже открытую следующую карту; после добора подсказка убирается. ИИ также может использовать свой Сканер, но не видит будущий порядок колоды без разрешённой разведки.

## Таро дуэли

В колоде 52 обычные карты плюс 3 выбранных таро. Таро занимает одно из четырёх мест и используется один раз за матч.

| Таро | PvP-эффект |
|---|---|
| Роза | +8 HP, без превышения 100 |
| Страж | 6 брони на текущий обмен |
| Солнце | +25% урона своего стола |
| Луна | −30% входящего урона |
| Башня | Немедленно сбрасывает обычные карты своего стола |
| Монета | Возвращает один потраченный срез: сначала −2, иначе −4; если оба целы, ничего не добавляет |
| Эхо | +50% урона своего стола |
| Печать | −50% входящего урона |
| Весы | +25% урона точному столу |
| Свеча | Следующие три карты видны на новом раунде |
| Песочные часы | Подтягивают сумму к текущей цели только при отклонении не больше 2 |

Нить исключена из PvP, рукав отключён. Кампанийные усилители, деньги и сильные Часы сохранены отдельно. При переборе эффекты таро не срабатывают, кроме немедленного действия Башни при доборе.

## Броня

Голубая шкала и число под HP показывают броню на текущий обмен. Для дуэли суммируются Страж и Хранитель, с общим ограничением 12. Это не дополнительное постоянное здоровье: остаток не переносится между раундами.

Порядок: лечение до максимального HP → Печать → Луна → поглощение бронёй → потеря HP. Обе стороны рассчитываются одновременно. Пример: 20 входящего, Печать и Луна дают 7, броня 6 поглощает 6, HP уменьшается на 1. Журнал фиксирует поглощённый урон отдельно для сторон. Шкала плавно обновляется по серверному значению.

## Проверка

- `qa/LoadoutPlaytest.luau`: 1477 проверок, включая 45 полных матчей всех сочетаний класса и пары джокеров против независимо выбранных сборок ИИ. Исходы: 21 победа / 21 поражение / 3 ничьи, средняя длительность 7,82 раунда. Это функциональная проверка, не доказательство равенства сборок для людей.
- Прежние проверки: Smoke 77, Impact 278, Tarot 146, Duel 21853 проверки с 24 полными матчами. Ожидания теста таро обновлены для нового лимита и ослабленного усиления.
- В симуляторе iPhone проверены выбор класса, удаление/добавление джокера, счётчики, недоступность старта неполным набором и начало партии 55-карточными колодами. Проверены отображение обеих пар на столе и шкалы брони.
- Физический телефон и живой соперник ещё требуют проверки. Следующий баланс-тест: длительность защитных матчей, сила сочетаний Лекаря с Красной рукой, Сканера со Свечой и точного урона с усилителями.

Исходники: `Loadout.luau`, `Inventory.luau`, `Duel.luau`, `Tarot.luau`, `TableScene.luau`. Константы первого баланса находятся в определениях и расчётах; изменения публикуются вместе со сборкой. Профили пока только в памяти сервера.

## Посадка за стол

`Seating.luau` сажает персонажа на серверный Seat в ближнем стуле кампании или PvP при начале/продолжении боя. Для занятого другим персонажем места возвращается понятное сообщение. Положение стула скорректировано под увеличенную столешницу. До выхода персонаж не ходит и не прыгает. При возвращении в комнату восстанавливаются прежние параметры Humanoid, а персонаж встаёт рядом со стулом.

В игровом ракурсе собственное тело и аксессуары скрыты только у владельца, а ProximityPromptService выключен локально. Выйдя из боя, игрок снова видит тело, подсказки и обычную камеру. При возвращении персонажа после респавна сервер восстанавливает посадку. Реальными игровыми нажатиями проверены SeatPart, отсутствие видимых частей собственного аватара, отключение подсказок и полное восстановление после выхода: WalkSpeed 16, JumpPower 50 в текущем персонаже. Сценарий не меняет боевое HP.
