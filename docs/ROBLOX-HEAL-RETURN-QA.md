# Лечение и возврат карт — 5 ноября 2026

- При розыгрыше лечение отображается до атак: зелёное `♥ +N` и заполнение HP за 0,45 с. Пауза перед атакой 0,55 с только при фактическом лечении.
- N — восстановленное здоровье с ограничением максимальным HP. Лечение учитывается для обеих сторон дуэли.
- Карты из зон с перебором возвращаются анимацией к своей колоде. Это презентация, не добавление карт в игровой массив колоды.
- Возврат не вызывает обработчики урона; учитывается в завершении общей анимации, отменяется вместе с ней.
