# Столы в комнате

- Слева, X = −19: `Table_training`, «ТРЕНИРОВОЧНЫЙ», режим `training`. Прежняя дуэль с ИИ, настроенная камера и интерфейс сохранены.
- В центре, X = 0: `Table_pvp`, «PVP». Копия тренировочного стола с той же моделью и размерами 12,2 × 3,5378 × 18,2. Заменяет прежний центральный стол бесконечного режима.
- Справа, X = 19: `Table_campaign`, кампания.

Миграция выполняется и для уже созданной комнаты. Повторный запуск не добавляет копий. Над каждым столом сохранена лампа. У центрального стола создано место игрока для дальнейшего подключения PvP.

Сетевой бой и подбор двух игроков пока не реализованы: центральный вход сообщает это явно. ИИ открывается только через тренировочный стол и подготовку в шкафе.

Проверено в Studio: три модели на нужных X, режимы и названия подсказок, одинаковые размеры training/pvp, запуск тренировки и посадка в Table_training.PlayerSeat, переход центральной кнопки на отдельный экран PvP.
