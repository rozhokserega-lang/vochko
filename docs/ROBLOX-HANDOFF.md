# Продолжить ВОЧКО на другом ПК

Состояние проекта: 4 ноября 2026. Основная разработка сейчас идёт в Roblox; HTML-игра остаётся в корне репозитория.

## Быстрый запуск

1. Скачать весь репозиторий GitHub (Code → Download ZIP) и распаковать либо клонировать `https://github.com/rozhokserega-lang/vochko.git`.
2. Войти в Roblox Studio под тем же Roblox-аккаунтом, что использовался на этом ПК.
3. Открыть `roblox/releases/VochkoPrototype.rbxl` через File → Open from File.
4. Нажать Play. Комната, шкаф, столы, NPC и игровой интерфейс создаются кодом во время запуска. В режиме редактирования комната может не отображаться — это ожидаемо.
5. Нажать «PvP»: сначала открывается выбор таро, затем бой. «Шкаф · подготовка» в комнате открывает общую коллекцию.

Для готового файла установка Rojo не нужна. Интернет нужен для загрузки опубликованных Roblox-меша и изображений. Перенос не зависит от старых путей Downloads, /tmp или кэша этого Mac.

## Что сохранено

| Ресурс | Где находится |
| --- | --- |
| Готовая игра со всеми скриптами и шаблоном стола | `roblox/releases/VochkoPrototype.rbxl` |
| Проверяемый список файлов, размеров, SHA-256 и Roblox asset IDs | `roblox/releases/manifest.json` |
| Полный код комнаты, шкафа, стульев, ламп, NPC и боевых столов | `roblox/src/RoomBuilder.luau`, `roblox/src/TableScene.luau` |
| Исходник стола с геометрией и встроенными PBR-текстурами для импорта | `roblox/assets/models/tavern-table.glb` |
| Оригинальный GLB пользователя с Meshopt | `roblox/assets/models/source-tripo-meshopt.glb` |
| Roblox-шаблон стола, размер, InitialSize и ссылки на PBR-карты | `roblox/assets/models/TavernTable.rbxmx` |
| Атлас 52 карт и портреты | `roblox/assets/cards-atlas.png`, `roblox/assets/opponents.png` |
| Все 12 исходных изображений таро | `assets/tarot/*-v1.webp` |
| Привязки опубликованных изображений | `roblox/src/Assets.luau` |
| Камера и её настройки | `roblox/src/CameraControls.luau`, `roblox/src/TableScene.luau` |
| Бой кампании, дуэль/ИИ, таро, сервер и интерфейс | остальные файлы `roblox/src/` |

GLB-файлы проверены: геометрия и три исходные PBR-текстуры находятся внутри, внешних путей к текстурам нет. Roblox разбивает PBR на четыре карты при импорте. Готовый `.rbxl` использует загруженные Roblox asset IDs: бинарные ресурсы Roblox не встраиваются внутрь ссылки. Если владелец experience или аккаунт другой и возникнет ошибка доступа, выдать доступ ассетам либо повторно импортировать `tavern-table.glb` и обновить ID в `TavernTable.rbxmx`. Исходные картинки сохранены для аналогичной перезагрузки изображений.

## Где продолжать работу

Исходники в Git — основная версия. Для изменений установить Rojo CLI и плагин Rojo, открыть `.rbxl`, остановить Play и подключиться к `rojo serve roblox/default.project.json` на порту 34872. После правок запустить из корня:

```sh
node roblox/tools/build-release.cjs
```

Это обновит готовую сборку и manifest. Затем сохранить исходники, сборку и manifest одним коммитом. Если менять скрипты вручную внутри Studio, перенести изменения обратно в `roblox/src/` перед синхронизацией: готовая сборка при следующем запуске сборщика пересоздаётся из исходников.

## Зафиксированное поведение

- PvP-камера: Z −1,65; высота 12,54; наклон 50,31°; FOV 71,92°.
- Кампания: Z −2,38; высота 10,15; наклон 44,14°; FOV 74,90°.
- Три поля игрока и три ИИ. Максимум четыре карты на поле, таро тоже занимает место.
- Цель PvP начинается с 21 и растёт на единицу за раунд для обеих сторон. Кампания пока остаётся на 21.
- Перед новой дуэлью выбор до четырёх разных таро; ИИ выбирает свои четыре. Все таро открыты тестовым переключателем `Tarot.TestUnlockAll`.
- Таро одноразовые в пределах боя, но сохраняются в коллекции и снова доступны в новой партии.
- Эффекты поля (бонусы и таро) написаны справа от карт без чёрной подложки.
- Выбор −4 проверен: после применения тратится именно minus4, minus2 остаётся доступен. Учтён верхний GUI inset при расчёте координат мыши/касания.

Текущий прогресс игрока, монеты, выбор в открытой серверной сессии и временные положения ползунков не являются частью сохранения Git. Постоянное сохранение прогресса пока не реализовано; фиксированные стартовые ракурсы находятся в коде. Supabase из HTML-версии для Roblox сейчас не используется.

Правила и предыдущие проверки баланса: `docs/ROBLOX-PVP-BALANCE.md`. Следующий шаг — игровой тест читаемости, баланса растущей цели и сочетаний таро; сетевой PvP, постоянный профиль и полноценная кампания ещё впереди.
