# ВОЧКО — Roblox-прототип

## Открыть на другом ПК

Скачай репозиторий целиком и открой **[releases/VochkoPrototype.rbxl](releases/VochkoPrototype.rbxl)** в Roblox Studio через File → Open from File. Нажми **Play**: комната и игровой стол создаются при запуске. Войти лучше в тот же Roblox-аккаунт, под которым загружались модели и изображения.

Rojo для открытия готового файла не нужен. Для продолжения разработки и списка сохранённых ресурсов см. **[инструкцию переноса](../docs/ROBLOX-HANDOFF.md)**.

## Текущее состояние

- Комната с кампанией, PvP, шкафом и обозначенным столом бесконечного режима. Бесконечный режим пока не реализован.
- Кампания: один бой с Крысоловом, цель 21, три поля по четыре места.
- PvP: тренировочная дуэль с ИИ. По 100 HP, до восьми раундов, общая цель 21 → 22 → 23… Карты и суммы соперника видны при постепенном доборе; урон одновременный.
- Перед новой дуэлью открывается выбор таро. Игрок выбирает до четырёх, ИИ независимо готовит свои четыре.
- Все 12 таро открыты для теста. Каждое выбранное таро выпадает один раз за бой; в новой партии весь набор снова доступен. Таро даёт ноль очков и занимает одно из четырёх мест на поле.
- Расходники −2/−4, рукав, таланты, эффекты комбинаций, полёт карт и попадания. Подписи эффектов находятся справа от карт прямо на сукне.
- Профиль, выбор и монеты пока хранятся только до выхода с сервера. Постоянное сохранение и сетевой PvP не подключены.

[Правила и баланс PvP](../docs/ROBLOX-PVP-BALANCE.md).

## Разработка

### Мобильный бой

На телефоне ракурс фиксирован: Z 8, высота 18, наклон 42°, базовый обзор 80°. Альбомная проекция учитывает пропорции экрана, чтобы стол не становился мелким при повороте. Вся раскладка со столом придвинута к игроку на 0,55 stud. Панель настройки камеры скрыта, HP и раунд занимают компактные верхние блоки. Карты дуэли немного увеличены. Кнопки «В рукав»/«Из рукава» временно скрыты на всех устройствах; серверные правила рукава сохранены.

Проверено в симуляторе iPhone 17 Pro в альбомном и портретном положении. На физическом телефоне эта правка ещё не проверена.

Исходники — `src/`, сборочная схема — `default.project.json`. Из корня репозитория:

```sh
node roblox/tools/build-release.cjs
rojo serve roblox/default.project.json
```

Первый шаг обновляет готовый файл и контрольные суммы ресурсов. Второй запускает синхронизацию с плагином Rojo на порту 34872. Проверено с Rojo 7.7.1. Не синхронизируй поверх чужого проекта без резервной копии.

## Проверки

Проверены компиляция всех Luau-файлов, сборка Rojo и правила в Studio: `qa/Smoke.luau`, `qa/Impact.luau`, `qa/Duel.luau`, `qa/Tarot.luau`. Последние проверки: 147 сценариев таро/предметов, 278 проверок попаданий, 24 полных дуэли с растущей целью. Интерфейс выбора, готовность ИИ и расходник −4 проверены игровыми нажатиями. Физический телефон и игра с живым соперником не проверены.
