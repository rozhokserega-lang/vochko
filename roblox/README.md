# ВОЧКО — Roblox-прототип

Первый срез: комната с тремя столами и шкафом, один рабочий бой кампании с нашими картами и противником. Цель — 30, три зоны по пять карт, четыре хода. Работают добор, остановка зоны, два расходника «Срез», лечение комбинациями и три стартовых таланта.

Бой теперь происходит в 3D-сцене: камера переходит к столу кампании, карты с нашими изображениями перелетают из колоды на сукно, активная зона подсвечивается. Напротив сидит временный персонаж с реакцией на удар. HP, ходы, расходники и кнопки остаются экранным интерфейсом. Это первый этап оформления по референсу: детальная модель персонажа, художественные материалы и полный набор анимаций ещё предстоят.

PvP и бесконечный режим пока обозначены в комнате, но не реализованы. Шкаф позволяет выбрать талант; джокеры и таро — следующие этапы. Монеты и победы хранятся только до выхода с сервера. Это прототип, а не опубликованная Roblox-игра.

## Запуск

Нужны Roblox Studio, Rojo CLI и плагин Rojo в Studio. Проверено с Rojo 7.7.1. Из корня репозитория:

```powershell
rojo build roblox/default.project.json -o roblox/build/VochkoPrototype.rbxl
rojo serve roblox/default.project.json
```

Открой сборку `.rbxl` в Studio и нажми Play. Комната создаётся при запуске. Для синхронизации останови Play, открой плагин Rojo и подключись к `localhost:34872`. Сохрани резервную копию перед синхронизацией другого проекта.

Подойти к столу можно персонажем или нажать кнопку режима. В бою: Space — взять карту, F — остановить зону, Enter — сыграть ход. На телефоне используются экранные кнопки.

## Проверка 4 ноября 2026

`qa/Smoke.luau` запускается в серверном контексте Studio при Play. Все 77 проверок прошли: уникальность колоды, тузы, перебор, срезы, прогноз урона, расход хода, независимость сессий и запрет повторного удара после победы. Через интерфейс Studio проверен быстрый добор трёх карт и отображение атласов.

Полные забеги, нагрузка и физический iPhone пока не проверены. Сервер хранит колоду, проверяет команды и выдаёт награду один раз. Клиент получает только открытые карты. Настройки фиксируются в начале боя; без опубликованного ConfigService используются значения Config.luau.
