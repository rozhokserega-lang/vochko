# Изображения

Использованы существующие изображения ВОЧКО из HTML-версии.

- `cards-atlas.png`: 52 карты, 936×400, ячейка 72×100. Ранги 2–туз, строки: пики, черви, бубны, трефы. Roblox ID: `126504298884435`.
- `opponents.png`: противники Темницы, 1000×400, сетка 5×2 по 200×200. Roblox ID: `125128067761419`.

Экспортёр `tools/export-assets.cjs` использует актуальный HTML локального клона и локальную установку Playwright. Для запуска игры экспортёр не нужен. ID находятся в `src/Assets.luau`. При публикации проверь доступ изображений для владельца experience.
