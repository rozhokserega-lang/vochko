# Стол таверны

Исходник предоставлен пользователем: `tripo_pbr_model_ccb96427-2084-46e7-9e90-dc8717f0723a_meshopt.glb`.

`tavern-table.glb` — копия для импорта без Meshopt/квантизации; PBR-текстуры уменьшены с 4096 до 2048. Геометрия сохранена: 4723 треугольника, 3464 вершины. Исходник в Downloads не изменён.

`TavernTable.rbxmx` — шаблон для Rojo, с ID загруженных Studio меша и четырёх PBR-карт. RoomBuilder помещает его на стол кампании. Старые примитивы скрываются; логический стол и ProximityPrompt сохраняются. Визуальная модель закреплена и не участвует в столкновениях.

Импорт проверен в Studio 4 ноября 2026 года. Для другого владельца experience необходимо проверить доступ к ассетам. PvP-разметка шести зон пока не добавлена.
